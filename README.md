# StudyBuddy AI 📚🤖

A full-stack AI-powered study assistant built with **Node.js + Express 5**, **React 19 + Vite**, and **Google Gemini Flash Lite**. 

StudyBuddy is designed to help students revise effectively the night before an exam: paste lecture notes, upload a text/markdown file, or drop in a **lecture PDF** to get an instant formatted revision sheet, generate interactive quizzes with explanations, and ask doubts in a live streaming tutor chat.

---

## ✨ Features

- **📄 Multi-Format Notes Ingestion**:
  - Type or paste lecture notes directly.
  - **PDF Text Extraction**: Drop or upload multi-page lecture slide/handout PDFs (`.pdf`) — text is extracted client-side.
  - File upload for `.txt` and `.md` files.
  - One-click clipboard paste and quick study templates.
- **📝 One-Minute Revision Sheet (`/api/summary`)**:
  - Extracts the big idea, 5 key points (<25 words each), and 3 must-remember terms.
- **🎯 Interactive Multiple-Choice Quiz (`/api/quiz`)**:
  - Guaranteed JSON schema output generated by Gemini Flash.
  - 5 multiple-choice questions with 4 options each across Easy, Medium, or Hard difficulty.
  - Immediate correct/wrong answer feedback, instant explanation, and automated score tracking.
- **💬 Streaming Doubt Tutor (`/api/chat`)**:
  - Multi-turn conversation grounded in the student's own lecture notes.
  - Real-time token streaming via `ReadableStream` and `res.write()`.
- **🕒 Revision History (`/api/history`)**:
  - Automatically saves previous revision sessions to review anytime.

---

## 🏗️ Architecture

```
Browser (localhost:5173)
       │
       ▼ (relative /api requests)
Vite Dev Proxy
       │
       ▼ (forwards /api/*)
Express API (localhost:3001)  <── Holds GEMINI_API_KEY (Trust boundary)
       │
       ▼ (Google GenAI SDK)
Gemini Flash Lite API
```

## 🚀 Getting Started

### Prerequisites
- Node.js 20.19+ or 22+
- npm 10+
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey)

### 1. Installation

Clone the repository:
```bash
git clone https://github.com/<your-username>/studybuddy.git
cd studybuddy
```

Install backend dependencies:
```bash
cd server
npm install
```

Install frontend dependencies:
```bash
cd ../client
npm install
```

### 2. Configure Environment

In `server/`:
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Add your Gemini API key in `server/.env`:
```ini
GEMINI_API_KEY=your_gemini_api_key_here
MODEL=gemini-flash-lite-latest
PORT=3001
```

### 3. Run in Development Mode

Run backend (Terminal 1):
```bash
cd server
npm run dev
```

Run frontend (Terminal 2):
```bash
cd client
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

### 4. Run in Production Mode

Build the client bundle and serve through Express:
```bash
cd client
npm run build

cd ../server
npm start
```
Open [http://localhost:3001](http://localhost:3001) in your browser.

---

## 🔒 Security

- The Gemini API key is strictly kept in `server/.env` and never exposed to the client bundle.
- `.env` is explicitly ignored in `.gitignore`.
- Prompts employ `<notes>` delimiters and strict anti-injection guardrails.
